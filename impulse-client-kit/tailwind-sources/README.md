# impulse-tailwind-sources

Build-script helpers for wiring Rust UI component sources into a Tailwind CSS
build.

Tailwind only emits CSS for classes it can find while scanning source files.
Components written in Rust embed their classes in `leptos::view!` macros, so the
consuming project's Tailwind pass must scan the component crates' sources —
which, for a dependency pulled from crates.io / git, live in the read-only Cargo
registry under a path nobody can hardcode in their `input.css`.

This crate bridges that gap using Cargo's `links` / `DEP_*` build metadata, so
component libraries can be consumed as plain Cargo dependencies instead of being
copied into every project.

## Two roles, two functions

### Component library: `export`

A component library calls `export` from its `build.rs` to publish an aggregated
scan file — its own sources plus any upstream component libraries it builds on —
as `DEP_<LINKS>_STYLES` (and its raw `src` dir as `DEP_<LINKS>_SOURCE_DIR`).
The crate must declare a `links` key in its `Cargo.toml`:

```toml
# Cargo.toml
links = "my-ui-lib"
build = "build.rs"

[build-dependencies]
impulse-tailwind-sources = { git = "https://github.com/impulse-sw/impulse-kit.git", tag = "1.4.10" }
```

```rust
// build.rs
fn main() {
  impulse_tailwind_sources::export(&["DEP_IMPULSE_CLIENT_KIT_COMPONENTS_STYLES"]);
}
```

Because `export` folds upstream bundles into its own, the pattern composes to
any depth: each level only ever reads the `DEP_*_STYLES` of its *direct*
dependencies.

### Consumer app: `write_source_partial`

An app (or example) calls `write_source_partial` to turn the published paths
into a `@source "...";` partial that its `style.css` imports next to
`tailwindcss`:

```rust
// build.rs
use std::{env, path::Path};

fn main() {
  let manifest_dir = env::var("CARGO_MANIFEST_DIR").unwrap();
  let partial = Path::new(&manifest_dir).join(".tailwind-sources.css");
  impulse_tailwind_sources::write_source_partial(partial, &["DEP_IMPULSE_CLIENT_KIT_BLOCKS_STYLES"]);
}
```

```css
/* style.css */
@import 'tailwindcss';
@import "./.tailwind-sources.css"; /* component classes, generated by build.rs */
```

Add the generated `.tailwind-sources.css` to your `.gitignore`. Missing
`DEP_*` variables are skipped, so the call stays correct even if a component
dependency is optional.

## Published variables in this workspace

| Crate | `STYLES` variable |
| --- | --- |
| `impulse-client-kit-components` | `DEP_IMPULSE_CLIENT_KIT_COMPONENTS_STYLES` |
| `impulse-client-kit-blocks` | `DEP_IMPULSE_CLIENT_KIT_BLOCKS_STYLES` (already folds the components in) |
